# kadokunn.com

Situs personal Kadokun / Kadokun Entertainment, gaya neobrutalism (Hugo).

Tema `brutalism-kadokun` dimodifikasi dari [Brutalism-Wall](https://github.com/muhawaluddin/theme-neobrutalisme-wall) karya muhawaluddin (lisensi MIT).

## Jalankan
```bash
hugo server -D
```

## Build
```bash
hugo --minify
```
Hasilnya di folder `public/`. Semua pengaturan (nama, sosmed, menu) ada di `hugo.toml`.
